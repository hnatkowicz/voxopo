Double Take photos

Upload each pair to public/double-take/ on GitHub as name-original.webp and name-altered.webp (1600 x 1200, from the same master). They show up here after the next deploy. Pick one, check the boxes around its 5 differences, and save.

Log in on /admin first, then come back to this page.
Saving turns on once you run double_take.sql in Neon. You can still look at the pairs and their differences.

Show: Sensitivity
  • Drag a box to move it; drag a corner to resize it; drag on an empty spot to draw a new box.
  • Tap a box to select it; Shift-tap to select more. Merge joins the selected boxes into one, Delete removes them.
  • Flicker swaps the two photos twice a second, the easiest way to see a change with your own eyes. Differences lights up every pixel that changed.
  • The game will make each box a bit bigger when it checks a tap, so a box only needs to fit the change itself.
