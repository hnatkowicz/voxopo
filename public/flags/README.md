# Flags

Flag art for Country Monkey (mixed in with the maps) and a future
Flag Me Down category in Thinking Pants.

- **Format:** SVG (flags are simple shapes, so files stay tiny and sharp).
- **Names:** same as the maps in `public/maps/`, e.g. `kenya.svg`,
  `south-korea.svg`. Players never see filenames (pictures are served
  under a disguised address), so plain names are fine.
- **Regional flags** (Scotland, Greenland, Texas, ...): name them plainly
  too, and tell Claude what each one represents so it can tag the region
  and pick look-alike wrong answers.
